# rustfox

A Rust rewrite of the [openfox](https://github.com/co-l/openfox) agentic coding
assistant.

## Status

Early. The wire contract is extracted and the server core is working; see
[PROGRESS.md](./PROGRESS.md) for exactly what is and is not implemented.

## How this is built

The contract is the specification, not the original source. The three files in
`contract/` are **generated by running the original server**, never transcribed
by hand, so they cannot drift from the behaviour they describe:

| File | How it was produced |
|---|---|
| `contract/db-schema.sql` | ran `initDatabase()` against a fresh SQLite file and dumped the result |
| `contract/rest-routes.json` | scanned route modules and joined them with the mount table in `index.ts` |
| `contract/ws-protocol.json` | drove a live socket with every message type and recorded the actual reply |

`tests/contract.rs` fails if the implementation and the contract disagree.

## Build

```bash
cargo build
cargo test
```

## Verify against a reference server

```bash
# in a checkout of co-l/openfox:
OPENFOX_PORT=41555 npx tsx src/cli/index.ts --no-browser

# then, here:
node harnes/conformance.mjs http://127.0.0.1:41555 contract/rest-routes.json
```
